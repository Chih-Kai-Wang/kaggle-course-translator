# CLAUDE.md — NativeRead Project Context

Read `HANDOFF.md` in this directory first for the complete architecture, product invariants, file map, and recent changes (`v2.0.0` -> `v2.1.0` -> `v2.2.0`).

## Quick Commands
- Rebuild mobile Userscript (`docs/nativeread.user.js`) and Android extension package (`docs/nativeread-android-extension.zip`) after editing `shared/` or `content/`:
  ```bash
  node scripts/build-mobile.js
  ```
- Syntax check all JS files:
  ```bash
  for f in shared/*.js background/*.js content/*.js popup/*.js options/*.js viewer/*.js scripts/*.js docs/app.js docs/sw.js docs/nativeread.user.js; do node --check "$f" || exit 1; done
  ```

## Key Invariants
1. **Default silent (on-demand only)**: Never add static `content_scripts` to `manifest.json`; `autoTranslate` defaults to `false`.
2. **DOM safety**: Never assign unescaped translated strings via `innerHTML`; use `document.createTextNode` / `textContent`.
3. **Secret safety**: Never print, log, or commit raw API keys.
4. **Generated files**: `docs/nativeread.user.js` and `docs/nativeread-android-extension.zip` are generated by `node scripts/build-mobile.js` — edit source files in `shared/`, `content/`, or `scripts/build-mobile.js` and re-run the build script.
