Attention Is All You Need

The Transformer is a neural network architecture based solely on attention mechanisms, dispensing with recurrence entirely.[1] Scaled dot-product attention computes weights as softmax ( QKT dk ) V for parallel sequence modeling.

Project Type Neural sequence transduction architecture
Sponsor Google Brain and Google Research
Website proceedings.neurips.cc/paper/2017/hash/3f5ee243547dee91fbd053c1c4a845aa-Abstract.html

Architecture Highlights

  • Multi-head projections enable attending to distinct representation subspaces simultaneously.
  • Positional encodings inject sequence order information without recurrent state dependencies.
